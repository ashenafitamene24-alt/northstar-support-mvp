# Northstar Retail Co. - Support Deflection MVP

A 1-week industry simulation project built by a 5-person pod to reduce repetitive customer support tickets for Northstar Retail Co.

## 🚀 Overview
This prototype automates customer support inquiries for two main categories:
1. **Order Status Lookups** ("Where is my order?")
2. **Returns & Refund Guidance** ("How do I return an item?")

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Data:** Mock JSON records for orders and return decision rules
* **Version Control & Collaboration:** GitHub, GitHub Projects
